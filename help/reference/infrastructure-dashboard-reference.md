# 基础架构仪表板引用 {#infrastructure-dashboard-reference}

此参考记录了AEM Managed Services的可观察性分析中使用的主机级基础架构面板。

## 功能板概述

“主机基础结构监视仪表板”提供了对底层主机的利用率和性能的实时可见性。 这些量度可帮助操作员监控计算、内存、存储和网络资源，同时确定潜在的资源瓶颈。

仪表板包括以下监控面板：

- 主机CPU利用率
- 主机磁盘I/O
- 主机网络I/O
- CPU I/O等待
- 存储使用情况
- 磁盘使用情况
- 主机CPU平均负载
- 主机内存使用率

## &#x200B;1. 主机CPU利用率

![主机CPU利用率](../assets/host-monitoring/host_cpu_utilization.png)

### 描述

**主机CPU利用率**&#x200B;面板显示一段时间内操作系统和所有正在运行的进程当前正在使用的CPU资源的百分比。

此量度表示整个主机上的CPU使用情况，并提供了处理器活动的时间序列可视化图表。

该图表允许操作员监控在选定的观察时段内CPU使用量的变化情况。

### 量度

| 量度 | 描述 |
| --------- | ---------------------------------------- |
| `cpu_pct` | 当前使用的CPU总数百分比 |

### 件数

- 百分比(%)

### 显示的统计信息

该面板使用三个值汇总了CPU利用率：

| 统计信息 | 描述 |
| --------- | --------------------------------------------------------------- |
| 平均值 | 所选时间范围内的平均CPU利用率 |
| 过去 | 最近收集的CPU利用率值 |
| Max | 在选定时间范围内观察到的最高CPU利用率 |

### 图形组件

- 表示CPU利用率的时间序列行。
- 基于百分比的Y轴范围从&#x200B;**0%到100%**。
- 图形下方显示了概要统计信息。
- 所选监视间隔的历史趋势。

## &#x200B;2. 主机磁盘I/O

![主机磁盘I/O](../assets/host-monitoring/host_disk_io.png)

### 描述

**主机磁盘I/O**&#x200B;面板显示主机执行的磁盘读取和磁盘写入操作的存储吞吐量。

该图显示了两个独立的时间序列，它们表示在操作系统和存储设备之间传输的数据。

此可视化图表有助于随时间推移监视存储活动，并向insight提供从磁盘读取和写入磁盘的数据量。

### 量度

| 量度 | 描述 |
| ------------ | --------------------------------- |
| `disk_read` | 从存储中读取的数据量 |
| `disk_write` | 写入存储的数据量 |

在内部，这些量度使用平滑的吞吐量值显示。

### 件数

- 每秒字节数(B/s)
- 千字节/秒(KB/s)
- 兆字节/秒(MB/s)
- 每秒GB (GB/s)

显示的单位根据吞吐量自动缩放。

### 图形组件

- 表示磁盘读取吞吐量的绿色线。
- 代表磁盘写入吞吐量的橙色线。
- 时间序列可视化图表。
- 每个量度都有单独的图例。
- 显示在每个系列旁边的当前指标值。

## &#x200B;3. 主机网络I/O

![主机网络I/O](../assets/host-monitoring/host_network_io.png)

### 描述

**主机网络I/O**&#x200B;面板显示主机在一段时间内传输和接收的网络通信量。

该图表测量数据通过网络接口传输的速率，并提供网络带宽消耗的可视性。
此度量表示聚合网络吞吐量。

### 量度

| 量度 | 描述 |
| --------------- | --------------------------------------------------------------------- |
| `bytes_per_sec` | 聚合网络吞吐量，以每秒传输的字节数表示 |

### 件数

图形会自动在以下位置之间进行缩放：

- 字节/秒
- KB/秒
- MB/秒
- GB/秒

取决于观察到的流量。

### 显示的统计信息

| 统计信息 | 描述 |
| --------- | ---------------------------------- |
| 平均值 | 平均网络吞吐量 |
| 过去 | 最近的吞吐量测量 |
| Max | 观察到的最高吞吐量 |

### 图形组件

- 单个吞吐量行。
- 时间序列可视化图表。
- 动态带宽扩展。
- 图表下方显示的概要统计信息。

## &#x200B;4. CPU I/O等待

![CPU I/O等待](../assets/host-monitoring/cpu_io_wait.png)

### 描述

**CPU I/O等待**&#x200B;面板显示CPU等待输入/输出操作完成所花费的时间百分比。

此度量表示由于等待存储设备或其他I/O操作时活动进程被阻止而发生的处理器空闲时间。

该图显示了I/O等待如何随时间变化。

### 量度

| 量度 | 描述 |
| --------- | ------------------------------------------------------ |
| `cpu_pct` | 等待I/O操作所花费的CPU时间百分比 |

### 件数

- 百分比(%)

### 显示的统计信息

| 统计信息 | 描述 |
| --------- | ------------------------------- |
| 平均值 | 平均CPU I/O等待百分比 |
| 过去 | 最近记录的值 |
| Max | 最高记录值 |

### 图形组件

- 时间序列线。
- Y轴百分比。
- 概要统计信息。
- 历史趋势可视化图表。

## &#x200B;5. 存储使用情况

![存储使用情况](../assets/host-monitoring/storage_disk_usage.png)

### 描述

“**存储使用情况**”面板显示当前在受监视主机上使用的存储容量的总百分比。

该图形提供了所选时间间隔内文件系统容量利用率的历史视图。

### 量度

| 量度 | 描述 |
| --------------- | -------------------------------------------------- |
| 存储使用率% | 当前已使用的已分配存储的百分比 |

### 件数

- 百分比(%)

### 图形组件

- 时间序列利用率图。
- 百分比刻度。
- 历史存储利用率趋势。

## &#x200B;6. 磁盘使用情况

![磁盘使用情况](../assets/host-monitoring/storage_disk_usage.png)

### 描述

“**磁盘使用情况**”面板显示每个已装载的文件系统或存储设备的存储使用情况。

每一行对应于一个特定的块设备或已装载的分区，并报告当前使用的空间百分比。

此表提供了文件系统级别的存储利用率细目。

### 显示的信息

每个条目包括：

| 字段 | 描述 |
| --------------- | -------------------------------------------- |
| 设备 | 安装的存储设备或文件系统 |
| 已使用% | 已利用存储容量的百分比 |
| 利用率栏 | 存储消耗的可视化表示形式 |

### 件数

- 百分比(%)

### 图形组件

- 文件系统/设备列表。
- 利用率百分比。
- 颜色编码的容量指示器。
- 已排序的利用率值。

## &#x200B;7. 主机CPU平均负载

![托管CPU平均负载](../assets/host-monitoring/host_cpu_load_average.png)

### 描述

**主机CPU平均负载**&#x200B;面板显示三个滚动时间窗口的Linux系统平均负载。

与CPU利用率不同，平均负载表示处于活动运行状态或等待CPU计划或I/O完成的进程的平均数。

该图表同时显示三个滚动平均值，提供短期和长期工作负载趋势。

### 量度

| 量度 | 描述 |
| ---------- | -------------------------------------------- |
| `load_1m` | 过去1分钟的平均系统负载 |
| `load_5m` | 过去5分钟的平均系统负载 |
| `load_15m` | 过去15分钟的平均系统负载 |

### 件数

- 平均负载（无维度值）

### 显示的统计信息

对于每个负载平均量度：

| 统计信息 | 描述 |
| --------- | --------------------------------------- |
| 平均值 | 所选时间范围内的平均负载 |
| 过去 | 最新记录的加载值 |
| Max | 观察到的负载值最高 |

### 图形组件

- 三条独立的趋势线。
- 时间序列可视化图表。
- 每个滚动平均值的单个图例。
- 每个度量的概要统计信息。

## &#x200B;8. 主机内存使用率

![主机内存使用率](../assets/host-monitoring/host_memory_usage.png)

### 描述

“**主机内存使用情况**”面板显示操作系统当前分配的物理系统内存的百分比。

此度量表示所有正在运行的进程、内核内存、缓冲区和高速缓存的总RAM利用率。

该图形提供选定监视周期内内存消耗的连续视图。

### 量度

| 量度 | 描述 |
| ------------ | ---------------------------------------------- |
| `memory_pct` | 当前正在使用的物理内存的百分比 |

### 件数

- 百分比(%)

### 显示的统计信息

| 统计信息 | 描述 |
| --------- | ---------------------------------- |
| 平均值 | 平均内存利用率 |
| 过去 | 最近记录的利用率 |
| Max | 观察到最高利用率 |

### 图形组件

- 时间序列内存利用率图表。
- Y轴百分比。
- 历史利用率趋势。
- 概要统计信息。

## 仪表板量度摘要

| 功能板面板 | 主要指标 | 单位 |
| --------------------- | -------------------------------- | ------------ |
| 主机CPU利用率 | `cpu_pct` | % |
| 主机磁盘I/O | `disk_read`, `disk_write` | 字节/秒 |
| 主机网络I/O | `bytes_per_sec` | 字节/秒 |
| CPU I/O等待 | `cpu_pct` | % |
| 存储使用情况 | 存储使用率% | % |
| 磁盘使用情况 | 文件系统使用 | % |
| 主机CPU平均负载 | `load_1m`, `load_5m`, `load_15m` | 平均负载 |
| 主机内存使用率 | `memory_pct` | % |
